# 本地源码副本与版本清单

本目录记录本书核查时使用的上游版本清单与来源索引，完整源码基线说明见 [UPSTREAM.md](UPSTREAM.md)。

- `UPSTREAM.md`：固定提交 SHA、发布日期与文件级差异统计（当前端点 `v1.6.0`）。
- `versions.json`：机器可读的版本提交映射与发布元数据。
- `source-index.json`：40 条官方来源（S1 至 S40），正文编号直接映射到对应固定标签路径。
- `pi-v0.9.4/`、`pi-v0.99.2/`、`pi-mono/`（`v1.3.0`）、`pi-v1.4.0/`：历史参照版本的本地 Git worktree，未做修改。
- `*.txt`：历史区间的文件级 diff 清单。

本版端点 `v1.6.0`（`faac585884ae2c013a6b1400f3e9e77f10b34bac`）不再向仓库内追加新的大体积 `.zip` 压缩包，所有源码链接均指向 GitHub 上对应标签的固定路径。
